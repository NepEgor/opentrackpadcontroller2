# Open Trackpad Controller 2

![Picture](https://github.com/NepEgor/opentrackpadcontroller_cad/blob/master/Pictures/alpha1.1/front.jpg)

Game controller with trackpads and gyro inspired by Steam Controller

### Hardware
* WeAct Studio rp2040 board
* Elan 33200v-3600 trackpads
* MPU6050 Gyro/Accelerometer
* SS49E Hall effect sensors
* Mouse switches and buttons
* Bunch of 3d prints
